# Agent brand marks

These locally bundled SVGs identify the agent running in a session. Logo paths
are preserved; CSS renders the monochrome artwork using the tab text color for
light/dark contrast. Names and marks belong to their respective owners.

Retrieved 2026-09-21 (UTC):

- `openai.svg`: OpenAI blossom from the header SVG at
  https://developers.openai.com/ (`viewBox="0 0 100 100"`). Removed presentation
  dimensions/classes; retained the original path geometry.
- `cursor.svg`: official Cursor brand kit, linked from https://cursor.com/brand:
  https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/brand/cursor-brand-assets.zip
  — `General Logos/Cube/SVG/CUBE_2D_DARK.svg`, retained unchanged.
- `githubcopilot.svg`: GitHub's official Primer Octicons `copilot-24`:
  https://github.com/primer/octicons/blob/main/icons/copilot-24.svg.
  MIT license reproduced in `LICENSE-octicons.txt`.
- `anthropic.svg`, `grok.svg`: Anthropic's mark and Grok's product mark from
  LobeHub Icons, commit `e3c0b0544a918f1f7ad4b2a6355f68bf89a87a97`:
  https://github.com/lobehub/lobe-icons/tree/e3c0b0544a918f1f7ad4b2a6355f68bf89a87a97/packages/static-svg/icons.
  MIT license reproduced in `LICENSE-lobe-icons.txt`.
